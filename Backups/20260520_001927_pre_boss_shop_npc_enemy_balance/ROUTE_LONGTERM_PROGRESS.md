# ルート長期化・記憶片希少化 作業進捗

## 方針
- 記憶片は有料アイテム級に貴重なものとして扱い、通常プレイ中の入手量を大きく絞る。
- 死亡時の恒久ボーナスは強化ではなく、到達済み地点へのショートカットを中心にする。
- 「この世のものとは思えないもの」は本来倒せない存在として、通常ルートのラスボスにはしない。
- 通常ルートには別のラスボスを置く。
- 境界外の観測者専用ボスラッシュは独立イベントとして扱い、本編ルート攻略には使わない。

## 実装予定
- STAGE踏破後に空港内の追加一本道を挟み、通常ラスボスへ向かう構造へ変更する。
- 通常ラスボスを追加し、空港ゲートの通常ゴールを差し替える。
- 通常イベント・ランダムイベントからの記憶片報酬を抑制する。
- 死亡時ショートカットの扱いを確認し、必要に応じて到達済みSTAGEへ戻れる導線を追加する。
