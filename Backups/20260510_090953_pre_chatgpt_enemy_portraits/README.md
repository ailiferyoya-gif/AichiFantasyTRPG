## 再生成

Unity メニューから `Aichi Fantasy > Build Main Scene` を実行すると、背景、SE、メインシーンを再生成します。

既に配置済みの背景PNGは上書きしない設定です。AI生成背景を差し替えたい場合は、対象PNGを手動で置き換えてください。

## ランダムイベント

通常シーンへ移動する直前に、一定確率で割り込みイベントが発生します。発生率は神話汚染や到達エンド数で少し上がります。

現在のランダムイベント例:

- 深夜モーニング
- 樽鳴り
- 招き猫の瞬き
- 黄色い行列
- 怪しい自販機
- 鯱の影
- 工程表の囁き
- 前回のあなた

## 図鑑と正気度演出

- 死亡系エンディングに到達すると死因図鑑へ登録されます。
- 次回以降、同じ死因に近い選択肢には警告が表示されます。
- 怪異は遭遇で図鑑登録、撃破で弱点解析済みになります。
- 正気度が低下すると、背景の揺れ、赤黒い膜、本文色の変化、選択肢文字化けが発生します。

## 長期周回システム

- 周回開始時に `境界不安定度` を選択できます。
- クリアすると次の不安定度が解放されます。
- 不安定度が高いほど敵HP/攻撃、イベント発生率、報酬倍率が上がります。
- 死亡時に保険札があれば装備保護演出が発生します。
- 保険札がない場合、低確率で破損装備が倉庫記録に残ります。
- 死因につながった直前の選択は後悔ログに残ります。
- 周回終了時に `異界愛知日報` として結果が表示されます。
- 怪異撃破回数に応じて段階実績報酬が発生します。
- ボスを一度倒すと次回以降は図鑑情報で少し戦いやすくなります。
- ボス前には回復、敵弱体化、SANを代償にした火力上昇の準備選択が出ます。
- 100時間拡張: プレイアブルキャラクター15体、LUK判定つきランダムイベント30種、敵20体、背景32枚へ拡張。
- 新規追加ポートレートは背景透過PNGとして自動生成。既存AIポートレートは元の円形アートを維持。
